# Sales Data Cleaning & Visualization

## Project Overview

This project demonstrates basic data cleaning and visualization using Python, Pandas, and Matplotlib.

## Dataset Issues

The dataset intentionally contains:

- Missing values
- Duplicate rows
- Mixed uppercase and lowercase text
- Extra spaces
- Incorrect data types
- Currency symbols
- Inconsistent formatting

## Data Cleaning

Performed using Pandas:

- Removed duplicates
- Filled missing values
- Standardized text
- Converted data types
- Created Total Sales column

## Visualizations

- Total Sales by Product
- Quantity Sold by City
- Average Product Price
- Orders by Category
- Daily Sales Trend
- Top 5 Products by Sales

## Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
